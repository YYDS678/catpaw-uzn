# 站源接口列表与规范

::: warning 非猫爪官方声明
本文档为 CatPaw-UZN 接口协议的**非猫爪官方**整理，接口行为可能随壳子版本变化，仅供开发参考。
:::

## 接口机制

站源需提供一套标准的 HTTP 接口供壳子客户端调用。所有接口挂载在[配置 /config](/guide/config) 中声明的 `api` 前缀下。例如：若配置中的 `api` 为 `http://127.0.0.1:9988/spider/duoduo`，当客户端请求 `/home` 时，实际请求地址为 `http://127.0.0.1:9988/spider/duoduo/home`。

站源主要分为两种形态：
1. **普通视频站 (`type: 3`)**：主要通过 `/home`、`/category`、`/detail`、`/play` 等原生接口提供分类与视频数据；
2. **HTML 网页视频站 (`type: 7`)**：首页通过加载 [/web](./web.md) 接口返回的网页展示，在网页中通过 Action 触发原生详情或播放。

## 接口速查表

| 接口路径 | 接口名称 | 说明 | 文档链接 |
| :--- | :--- | :--- | :--- |
| `/init` | 站源初始化 | 站源首次加载、搜索前初始化调用 | [查看详情](./init.md) |
| `/home` | 首页分类与筛选 | 获取分类列表、分类二级筛选条件（普通视频站 `type: 3`） | [查看详情](./home.md) |
| `/category` | 分类列表数据 | 获取特定分类下的视频列表及动态筛选 | [查看详情](./category.md) |
| `/detail` | 视频详情 | 获取视频详情、播放线路与选集信息 | [查看详情](./detail.md) |
| `/play` | 播放链接 | 获取解析后的播放链接、请求头与音轨弹幕 | [查看详情](./play.md) |
| `/search` | 搜索 | 关键字视频搜索 | [查看详情](./search.md) |
| `/web` | HTML 视频站主页 | 仅用于 `type: 7` 的 HTML 网页视频站内嵌渲染 | [查看详情](./web.md) |
