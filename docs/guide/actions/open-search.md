# 跳转原生搜索 (openSearch)

> 从站源网页跳转打开客户端原生聚合搜索页，并填入关键词。

## 请求格式

```json
{
    "action": "openSearch",
    "opt": {
        "wd": "庆余年"
    }
}
```

## 参数说明

| 字段 | 类型 | 必填 | 说明 |
| :--- | :---: | :---: | :--- |
| `wd` | String | 否 | 搜索关键词（严格只读 `wd`；若不传或为空则打开空搜索页） |

## 返回值说明

```json
{
    "success": true
}
```
