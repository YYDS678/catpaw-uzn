# 协议概述

::: warning 非猫爪官方声明
本文档为 CatPaw-UZN 接口协议的**非猫爪官方**整理，接口行为可能随壳子版本变化，仅供开发参考。
:::

CatPaw-UZN 壳子通过一套标准的 HTTP 接口协议加载站源（猫源）。一个源就是一个实现了协议接口的服务，壳子通过调用这些接口完成首页分类、搜索、详情和播放等功能。

## 协议组成

猫源协议由三部分组成：

| 组成部分 | 说明 |
| --- | --- |
| [配置 /config](/guide/config) | 声明站点与源列表：源类型、接口前缀、弹幕搜索地址等 |
| [站源接口](/guide/source-api/) | 源需要实现的接口规范：/init、/home、/category、/detail、/play、/search、/web |
| [Action 列表](/guide/actions/) | 壳子提供给源调用的方法|

## 阅读建议

如果是第一次接触猫源开发，建议按以下顺序阅读：

1. 先了解[配置 /config](/guide/config)，明白源是如何被声明和加载的
2. 再逐个熟悉[站源接口](/guide/source-api/)的入参与返回值
3. 需要与壳子交互（如弹幕、提示、打开网页）时查阅[Action 列表](/guide/actions/)
4. 了解最新的协议演进与规范调整，请参阅[变更记录](/guide/changelog)
